# Student Management System

A Django-based Student Management System for managing student records and academic marks.

## Features

- Add student details
- View student information
- Manage student marks
- Search student records
- Django Admin integration
- SQLite database
- CRUD operations

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Git & GitHub

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/adapanavadeepkrishna/STUDENT_MANAGEMENT_SYSTEM.git
```

### 2. Open the project folder

```bash
cd STUDENT_MANAGEMENT_SYSTEM
```

### 3. Install Django

```bash
pip install django
```

### 4. Run the server

```bash
python manage.py runserver
```

### 5. Open in your browser

```text
http://127.0.0.1:8000/
```
